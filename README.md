# Final Practical Exam Reflection

Nung una kong nakita ung final exam kinabahan ako kasi ang dami niyang steps. Pero nung nag follow ako ng isang commit lang every step naging easy na siya para sakin.

## Ung mga nahirapan ako

- Nag stuck ung npm install ko sa "Cannot find native binding". Sabay sabay pala akong nag run ng npm install sa OneDrive folder. Nag delete ako ng node_modules tapos nag install ulit na isa lang.
- Nag error ako sa push na 403. Mali pala ung saved na GitHub login sa laptop ko kaya nag sign in ulit ako sa tamang account.
- Mukhang Arial ung title ko. Hindi pala naka load ung Poppins kaya nag add ako ng Google Fonts sa index.html.
- Ung blossom image ko may gray na background. May 20 percent na fill pa pala siya sa Figma kaya nag remove ako tapos nag export ulit ng SVG.
- Na cut ung CSS file ko nung nag paste ako kaya kulang ung closing bracket. Nag replace ako ng buong file.
- Minsan mali ung screenshot na nakuha ko kasi ung pinakabago sa Downloads ung laging kinukuha ng command. Kaya nag screenshot muna ako bago mag move.
- Sobrang bagal ng npm sa OneDrive. Kailangan ko talagang mag wait at hindi mag paste ng kung ano ano.

## Ung natutunan ko

Na gets ko na kung bakit may design tokens. Isang lugar lang ung babaguhin ko kapag gusto kong palitan ung kulay o size. Natutunan ko rin na pwede pala mag add ng Tailwind at shadcn/ui kahit may CSS module na ung project ko kaya hindi ko na kailangan mag start ulit. Na gets ko rin kung bakit exact ung commit message at ung pangalan ng screenshot. Parang proof toh ng bawat step na ginawa ko.

## Ung na enjoy ko

Na enjoy ko ung part na nag swap ako sa shadcn Input tapos kapareho pa rin ung itsura ng page. Satisfying din tingnan na magkamukha na ung Sign Up at Login sa Figma. Isa rin sa pinaka masaya para sakin ung pag check ko sa root.css kasi walang nagbago sa itsura after kong ilipat ung mga values.

Mas confident na ako ngayon mag convert ng Figma design papuntang React. Maraming errors sa gitna pero sa bawat naayos ko may natutunan ako.
